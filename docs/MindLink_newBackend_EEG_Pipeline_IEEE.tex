\begin{abstract}
This paper describes the signal-processing and statistical neuroprofiling flow implemented in the MindLink Analyzer \texttt{newBackend}. The system acquires single-channel frontal EEG from a BrainLink/NeuroSky-compatible TGAM stream, validates packets, applies a live digital filtering chain, streams filtered samples to the user interface, and performs offline baseline-versus-task inference from raw EEG or precomputed TGAM band-power observations. The implemented processing stages include serial acquisition at 115200 baud, TGAM checksum validation, 512 Hz raw-sample handling, cascaded high-pass, low-pass, and 50 Hz notch filtering, two-second spectral windows, DPSS multitaper power spectral density estimation, signal-quality rejection, EMG-aware gamma suppression, spectral band-power and entropy features, block aggregation, Welch hypothesis tests, Cohen effect sizes, Benjamini-Hochberg false-discovery-rate adjustment, dependence-aware Fisher aggregation using the Kost-McDermott correction, SumP permutation testing, cosine-distance assessment, and across-task nonparametric comparison. The final output is a structured neuroprofile feature export with reliability caps, task gates, supported cognitive characteristics, allowed ability candidates, and blocked unsupported inferences. The method is grounded in established EEG spectral estimation, artifact-control, and statistical inference principles and follows the scientific flow described in the reference EEG neuroprofiling report.
\end{abstract}

\section{Introduction}
Consumer-grade single-channel EEG devices provide a practical route for repeated cognitive-state measurement, but they impose constraints that differ from laboratory multichannel EEG. The MindLink Analyzer \texttt{newBackend} addresses these constraints by separating live acquisition from offline statistical analysis. The live path emphasizes packet validation, filtering, low-latency transport, and device-state reporting. The analysis path emphasizes quality control, robust spectral features, baseline normalization, task-specific inference, dependence-aware aggregation, and traceable downstream neuroprofile export.

The design follows the scientific rationale summarized in the provided reference report: short EEG segments are transformed into spectral descriptors, task windows are compared against a personal baseline, correlated feature-level evidence is aggregated with corrections, and interpretable evidence is exported with explicit limitations. Unlike a generic report, this paper documents the concrete implementation in \texttt{newBackend/main.py}, \texttt{newBackend/eeg\_processor.py}, and \texttt{newBackend/neuroprofile\_traceability.py}.

\section{System Overview}
The backend exposes a FastAPI service with REST endpoints for health, serial-port listing, connection, disconnection, status, and analysis. A serial reader thread ingests device bytes, either through the BrainLinkParser SDK or a fallback TGAM parser. A WebSocket broadcaster sends live events to connected clients. Offline analysis is invoked through an \texttt{/analyze} request containing baseline samples and task samples.

The overall processing sequence is:
\begin{enumerate}
\item detect and open the BrainLink serial port;
\item parse SDK or TGAM byte frames;
\item validate payload checksums and decode raw EEG, signal quality, attention, meditation, band powers, and battery fields;
\item filter raw EEG samples for live display;
\item accumulate baseline and task samples;
\item convert raw samples to window-level feature rows;
\item reject unusable baseline windows;
\item aggregate windows into blocks;
\item compare each task against the eyes-closed baseline;
\item combine feature-level statistical evidence;
\item compute across-task rankings and corrections;
\item export a traceable neuroprofile evidence object.
\end{enumerate}

\section{Signal Acquisition and Packet Decoding}
\subsection{TGAM Stream Model}
The fallback parser assumes the TGAM packet structure:
\begin{equation}
\texttt{0xAA},\texttt{0xAA},L,p_1,\ldots,p_L,c ,
\end{equation}
where $L$ is payload length, $p_i$ are payload bytes, and $c$ is the checksum. The checksum rule implemented by the parser is
\begin{equation}
c = \left(\sim \left(\sum_{i=1}^{L}p_i \bmod 256\right)\right)\bmod 256 .
\end{equation}
Only payloads satisfying this equality are decoded. The relevant TGAM codes are raw EEG (\texttt{0x80}), poor signal (\texttt{0x02}), attention (\texttt{0x04}), meditation (\texttt{0x05}), EEG band power (\texttt{0x83}), and extended battery/version data (\texttt{0x85}).

\subsection{Raw EEG and Band-Power Decoding}
Raw EEG samples are decoded as signed 16-bit big-endian values:
\begin{equation}
x[n] =
\begin{cases}
256p_i+p_{i+1}, & 256p_i+p_{i+1}\le 32767,\\
256p_i+p_{i+1}-65536, & \text{otherwise}.
\end{cases}
\end{equation}
TGAM band powers are decoded as eight unsigned 24-bit integers ordered as delta, theta, low alpha, high alpha, low beta, high beta, low gamma, and mid gamma. The backend treats raw EEG as a 512 Hz stream, using two-second windows of $N=1024$ samples.

\section{Live Digital Filtering}
Live raw samples are processed by a cascaded second-order IIR chain: 1 Hz high-pass, 45 Hz low-pass, and 50 Hz notch filtering. Each section is implemented as a direct-form I biquad:
\begin{equation}
y[n]=b_0x[n]+b_1x[n-1]+b_2x[n-2]-a_1y[n-1]-a_2y[n-2].
\end{equation}
The high-pass and low-pass filters use Butterworth biquad coefficients obtained through the bilinear transform. For cutoff $f_c$ and sampling frequency $f_s$, let
\begin{equation}
k=\tan\left(\frac{\pi f_c}{f_s}\right),\quad
g=\frac{1}{1+\sqrt{2}k+k^2}.
\end{equation}
The high-pass section uses
\begin{equation}
b_0=g,\quad b_1=-2g,\quad b_2=g,
\end{equation}
\begin{equation}
a_1=2(k^2-1)g,\quad a_2=(1-\sqrt{2}k+k^2)g.
\end{equation}
The low-pass section uses
\begin{equation}
b_0=k^2g,\quad b_1=2k^2g,\quad b_2=k^2g,
\end{equation}
with the same $a_1$ and $a_2$ form. The notch filter is centered at $f_0=50$ Hz with quality factor $Q=35$:
\begin{equation}
\omega_0=\frac{2\pi f_0}{f_s},\quad
\alpha=\frac{\sin \omega_0}{2Q},\quad a_0=1+\alpha .
\end{equation}
The normalized notch coefficients are
\begin{equation}
b_0=\frac{1}{a_0},\quad b_1=\frac{-2\cos \omega_0}{a_0},\quad b_2=\frac{1}{a_0},
\end{equation}
\begin{equation}
a_1=\frac{-2\cos \omega_0}{a_0},\quad a_2=\frac{1-\alpha}{a_0}.
\end{equation}
Filtered samples are batched approximately every 16 ms for live WebSocket transport.

\section{Windowing and Spectral Estimation}
\subsection{Segmentation}
For raw offline analysis, the backend partitions the raw sequence into non-overlapping windows:
\begin{equation}
\mathbf{x}_w=\{x[wN],x[wN+1],\ldots,x[wN+N-1]\},
\end{equation}
where $N=1024$ and $f_s=512$ Hz. Each window therefore spans 2 s. The window is demeaned:
\begin{equation}
\tilde{x}_w[n]=x_w[n]-\frac{1}{N}\sum_{m=0}^{N-1}x_w[m].
\end{equation}

\subsection{DPSS Multitaper PSD}
When SciPy DPSS windows are available, the backend computes a multitaper PSD with $K=3$ tapers and time-bandwidth product $NW=2.5$. For taper $v_k[n]$, the tapered Fourier transform is
\begin{equation}
X_k[f]=\sum_{n=0}^{N-1}\tilde{x}_w[n]v_k[n]e^{-j2\pi fn/N}.
\end{equation}
The PSD estimate is
\begin{equation}
\hat{S}[f]=\frac{1}{K}\sum_{k=1}^{K}\frac{|X_k[f]|^2}{f_sN+\epsilon},
\end{equation}
where $\epsilon$ prevents numerical division errors. If DPSS computation is unavailable, the implementation falls back to a Hann-tapered periodogram. This is consistent with the reference report's emphasis on multitaper spectral estimation for short, noisy EEG windows.

\subsection{Noise-Floor Subtraction}
For each PSD, a robust noise floor is estimated as the 10th percentile:
\begin{equation}
\eta_w = Q_{0.10}\left(\hat{S}_w[f]\right).
\end{equation}
The SNR-adjusted PSD is
\begin{equation}
\hat{S}^{+}_w[f]=\max(\hat{S}_w[f]-\eta_w,0).
\end{equation}
This reduces the influence of broadband floor shifts before band integration.

\section{Quality Control and Artifact Handling}
\subsection{Baseline Window Rejection}
Baseline windows are screened before entering baseline statistics. The backend rejects a window as flatline when the robust scale is too small:
\begin{equation}
\sigma_{\mathrm{MAD}}=1.4826\cdot\mathrm{median}\{|x[n]-\mathrm{median}(x)|\}<0.5.
\end{equation}
It rejects likely not-worn windows using spectral criteria. Let
\begin{equation}
R_{\mathrm{neural}}=\frac{\sum_{0.5\le f\le 13}\hat{S}[f]}{\sum_f\hat{S}[f]},
\quad
R_{\mathrm{HF}}=\frac{\sum_{f\ge 30}\hat{S}[f]}{\sum_f\hat{S}[f]}.
\end{equation}
The log-log spectral slope $m$ is estimated over 1--40 Hz. A window is rejected when low-frequency neural content is insufficient, high-frequency power is excessive, or the spectrum is implausibly flat. Extreme amplitude outliers also trigger artifact rejection when more than 5 percent of samples exceed 20 robust scales.

\subsection{EMG Guard for Gamma Features}
Frontal single-channel EEG is vulnerable to facial EMG contamination, especially in beta/gamma ranges \cite{whitham2007,goncharova2003}. The backend computes
\begin{equation}
R_{\mathrm{EMG}}=\frac{P_{35-45}}{P_{20-30}+\epsilon},
\end{equation}
and a high-frequency log-log slope over 20--45 Hz:
\begin{equation}
\log \hat{S}[f] = m_{\mathrm{HF}}\log f + b .
\end{equation}
The EMG guard fires when
\begin{equation}
R_{\mathrm{EMG}}>1.2 \quad \mathrm{or} \quad m_{\mathrm{HF}}>-0.6 .
\end{equation}
If triggered, gamma features are set to zero and marked as unevaluated, preventing high-frequency muscle activity from being interpreted as neural gamma engagement.

\section{Feature Extraction}
\subsection{Frequency Bands}
The raw-analysis path computes features from the following bands:
\begin{table}[h]
\centering
\caption{Raw EEG Feature Bands}
\begin{tabular}{lcc}
\toprule
Band & Lower Hz & Upper Hz\\
\midrule
Delta & 0.5 & 4\\
Theta & 4 & 8\\
Alpha & 8 & 13\\
Beta & 13 & 30\\
Gamma & 30 & 45\\
Theta1 & 4 & 6\\
Theta2 & 6 & 8\\
Beta1 & 13 & 20\\
Beta2 & 20 & 30\\
\bottomrule
\end{tabular}
\end{table}

The TGAM-compatible path additionally preserves the chip's eight bands: delta, theta, low alpha, high alpha, low beta, high beta, low gamma, and mid gamma.

\subsection{Band Power and Relative Power}
For band $B=[f_1,f_2]$, raw and SNR-adjusted powers are
\begin{equation}
P_B^{\mathrm{raw}}=\int_{f_1}^{f_2}\hat{S}[f]\,df,\quad
P_B=\int_{f_1}^{f_2}\hat{S}^{+}[f]\,df .
\end{equation}
The backend uses trapezoidal numerical integration. Relative power is
\begin{equation}
P_B^{\mathrm{rel}}=\frac{P_B}{\sum_{B'}P_{B'}+\epsilon},
\end{equation}
or, when SNR power is absent, by normalizing against the window variance.

\subsection{Peak and Entropy Descriptors}
The normalized spectrum is
\begin{equation}
Z[f]=\frac{\hat{S}[f]-\eta}{\eta+\epsilon}.
\end{equation}
For each band, peak frequency and peak amplitude are
\begin{equation}
f_B^\ast=\arg\max_{f\in B} Z[f],\quad A_B^\ast=\max_{f\in B} Z[f].
\end{equation}
Peak relative amplitude is computed as the peak amplitude divided by the mean band-normalized spectrum. Spectral entropy is
\begin{equation}
H_B=-\sum_{f\in B}p_f\log_2p_f,\quad
p_f=\frac{Z[f]}{\sum_{u\in B}Z[u]+\epsilon}.
\end{equation}

\subsection{Cross-Band Ratios}
The implementation derives four cross-band ratios:
\begin{equation}
\rho_{\alpha/\theta}=\frac{P_\alpha}{P_\theta+\epsilon},\quad
\rho_{\beta/\alpha}=\frac{P_\beta}{P_\alpha+\epsilon},
\end{equation}
\begin{equation}
\rho_{\beta2/\beta1}=\frac{P_{\beta2}}{P_{\beta1}+\epsilon},\quad
\rho_{\theta2/\theta1}=\frac{P_{\theta2}}{P_{\theta1}+\epsilon}.
\end{equation}
These ratios are used as interpretable markers of cognitive load, attention, and task engagement.

\section{Block Aggregation and Baseline Comparison}
\subsection{Eyes-Closed Baseline}
The \texttt{/analyze} endpoint uses eyes-closed baseline samples when available. Eyes-open samples are retained as metadata but are not the primary baseline for statistical testing. If no eyes-closed key exists, all baseline arrays are pooled as a fallback.

\subsection{Effective Blocks}
To reduce temporal dependence among adjacent 2 s windows, windows are averaged into non-overlapping blocks. The default block duration is 8 s, so each block contains four feature windows:
\begin{equation}
\bar{z}_{b,f}=\frac{1}{M}\sum_{i=1}^{M}z_{bM+i,f},\quad M=4.
\end{equation}
All Welch tests, permutations, and task summaries are computed on these block-level feature means.

\section{Per-Feature Statistical Inference}
\subsection{Welch's t-Test}
For feature $f$, let $\{a_i\}_{i=1}^{n_a}$ denote task blocks and $\{b_j\}_{j=1}^{n_b}$ denote baseline blocks. The backend computes Welch's statistic:
\begin{equation}
t_f=\frac{\bar{a}_f-\bar{b}_f}{\sqrt{s_a^2/n_a+s_b^2/n_b}}.
\end{equation}
The Welch-Satterthwaite degrees of freedom are
\begin{equation}
\nu_f=\frac{(s_a^2/n_a+s_b^2/n_b)^2}
{\frac{(s_a^2/n_a)^2}{n_a-1}+\frac{(s_b^2/n_b)^2}{n_b-1}}.
\end{equation}
The two-sided $p$-value is obtained from the $t$ distribution when SciPy is available, otherwise from a normal approximation.

\subsection{Effect Size and Percent Change}
Cohen's effect size is
\begin{equation}
d_f=\frac{\bar{a}_f-\bar{b}_f}{\sqrt{(s_a^2+s_b^2)/2}+\epsilon}.
\end{equation}
The percent change and baseline/task ratio are
\begin{equation}
\Delta_f(\%)=100\frac{\bar{a}_f-\bar{b}_f}{|\bar{b}_f|+\epsilon},
\quad r_f=\frac{\bar{a}_f}{|\bar{b}_f|+\epsilon}.
\end{equation}
The backend uses feature-dependent thresholds: 0.25 for alpha effect sizes, 0.35 for beta effect sizes, 0.30 otherwise, 5 percent for relative or ratio features, and 10 percent for absolute raw-power features.

\subsection{Directional Priors}
Task-specific directional expectations are applied after the two-sided Welch test. For example, mental arithmetic expects alpha decrease and beta/gamma or beta-alpha-ratio increase; visual imagery expects alpha and alpha-theta-ratio increase; working memory expects theta increase, alpha decrease, and beta-ratio increase. If the expected direction is ``up'', then
\begin{equation}
p_f^{(1)}=
\begin{cases}
p_f^{(2)}/2, & t_f>0,\\
1-p_f^{(2)}/2, & t_f\le 0,
\end{cases}
\end{equation}
and analogously for ``down'' with $t_f<0$. A feature is considered directionally valid only when the observed sign matches the expectation.

\section{Multiple Comparisons and Feature Gating}
\subsection{Benjamini-Hochberg FDR}
The backend computes Benjamini-Hochberg $q$ values \cite{benjamini1995}. Given sorted $p$ values $p_{(1)}\le\cdots\le p_{(m)}$, adjusted values are obtained by the monotone rule
\begin{equation}
q_{(i)}=\min_{j\ge i}\frac{m}{j}p_{(j)}.
\end{equation}

\subsection{Correlation Guard}
Because EEG features are correlated, the backend computes a Spearman-rank feature correlation matrix and estimates an effective feature count using eigenvalues:
\begin{equation}
m_{\mathrm{eff}}=\sum_{i=1}^{m}\min(\max(\lambda_i,0),1).
\end{equation}
The local alpha is shrunk by
\begin{equation}
g=\mathrm{clip}\left(\frac{m_{\mathrm{eff}}}{m},0.05,1.0\right),
\quad
\alpha_{\mathrm{local}}=g\alpha .
\end{equation}
This guard makes feature gating more conservative when many features are redundant.

\subsection{Decision Rule}
For each feature, significance is reported if the direction is valid and at least one of the following passes: one-sided $p$ threshold, Cohen effect-size threshold, or percent-change threshold. The BH flag is recorded separately for transparency.

\section{Global Task Evidence}
\subsection{Fisher Combination with Kost-McDermott Correction}
Feature-level $p$ values are combined with Fisher's statistic \cite{fisher1925}:
\begin{equation}
X=-2\sum_{f=1}^{m}\log p_f.
\end{equation}
Because spectral features are dependent, the backend applies the Kost-McDermott correction \cite{kost2002}. Pairwise feature correlations $r_{ij}$ are converted into covariance contributions:
\begin{equation}
C_{ij}=3.263r_{ij}+0.710r_{ij}^2+0.027r_{ij}^3 .
\end{equation}
The corrected variance is
\begin{equation}
\sigma^2=4m+2\sum_{i<j}C_{ij},\quad \mu=2m.
\end{equation}
The scale and degrees of freedom are
\begin{equation}
c=\frac{\sigma^2}{2\mu},\quad \nu_{\mathrm{KM}}=\frac{2\mu^2}{\sigma^2}.
\end{equation}
The adjusted statistic is $X_{\mathrm{KM}}=X/c$ and its $p$ value is evaluated with a chi-square survival function using $\nu_{\mathrm{KM}}$ degrees of freedom.

\subsection{SumP Permutation Test}
The SumP statistic is
\begin{equation}
S_{\mathrm{obs}}=\sum_{f=1}^{m}p_f .
\end{equation}
Task and baseline blocks are pooled and labels are permuted with fixed seed 42 for $B=1000$ permutations. The empirical left-tail probability is
\begin{equation}
p_{\mathrm{perm}}=\frac{1+\sum_{b=1}^{B}\mathbf{1}\{S_b\le S_{\mathrm{obs}}\}}{B+1}.
\end{equation}
This test provides a distribution-free complement to the corrected Fisher statistic.

\subsection{Composite and Cosine Scores}
The composite evidence score is
\begin{equation}
C=\sum_{f=1}^{m}-\log_{10}(\max(q_f,10^{-12})).
\end{equation}
The backend also computes cosine similarity between baseline and task mean feature vectors:
\begin{equation}
\cos(\theta)=\frac{\mathbf{b}\cdot\mathbf{a}}
{\|\mathbf{b}\|_2\|\mathbf{a}\|_2+\epsilon},
\quad D_{\cos}=1-\cos(\theta).
\end{equation}
A permutation procedure shuffles the baseline vector to estimate a cosine-distance $p$ value.

\section{Across-Task Inference}
For sessions with multiple tasks, the backend ranks each feature across tasks using absolute median effect size. If at least two tasks contain data and SciPy is available, it applies the Kruskal-Wallis test per feature:
\begin{equation}
H=\frac{12}{N(N+1)}\sum_{g=1}^{G}n_g(\bar{R}_g-\bar{R})^2 ,
\end{equation}
followed by BH-FDR adjustment over feature-level omnibus $p$ values. Cross-task task-level Fisher/KM $p$ values are additionally adjusted with Holm-Bonferroni:
\begin{equation}
p_{(i)}^{\mathrm{Holm}}=\max_{j\le i}(m-j+1)p_{(j)}.
\end{equation}
This differs from the reference report's more general description of Friedman/Wilcoxon repeated-measures analysis; the current \texttt{newBackend} implementation uses Kruskal-Wallis and Holm-Bonferroni.

\section{Neuroprofile Traceability Export}
The final \texttt{neuroprofile\_feature\_export} is additive: it does not alter existing analysis keys. It maps statistical evidence into structured fields for downstream agents:
\begin{itemize}
\item canonical task IDs and session depth;
\item feature family labels such as spectral power, relative power, band ratio, peak feature, entropy/complexity, transition/recovery, and signal quality;
\item gate transparency including $p$, $q$, effect-size pass, percent-change pass, direction pass, and significance basis;
\item baseline and task block counts;
\item global reliability derived from baseline keep rate, feature keep rate, and gamma-guard activity;
\item session confidence caps for partial protocols;
\item allowed ability candidates, moderator-only characteristics, and blocked unsupported inferences.
\end{itemize}

The reliability cap prevents downstream interpretation from exceeding the quality supported by the recording. If global reliability is medium, strong feature confidence is capped at moderate; if reliability is low or unknown, confidence is capped at weak. Moderator-only tasks, such as static emotion grasp, body scan, and visual colour processing, are deliberately prevented from producing direct role-matching ability claims.

\section{Discussion}
The implemented pipeline follows established principles in EEG signal analysis. Multitaper PSD reduces variance and leakage in short windows \cite{thomson1982,percival1993}; EMG-aware gamma suppression reflects known contamination of scalp EEG by muscle activity \cite{whitham2007,goncharova2003}; Welch testing handles unequal variance and unequal block counts \cite{welch1947}; BH-FDR controls feature-selection error rate \cite{benjamini1995}; Fisher aggregation summarizes distributed evidence \cite{fisher1925}; and Kost-McDermott correction addresses correlated feature evidence \cite{kost2002}. The backend's engineering contribution is the integration of these methods into a traceable, single-channel, real-time-to-offline EEG workflow.

The main limitation is spatial specificity. A single frontal/frontopolar-compatible channel cannot support connectivity, source localization, lateralized motor claims, or clinical diagnosis. The traceability layer mitigates this limitation by reporting blocked inferences and by capping confidence according to session depth and signal reliability.

\section{Conclusion}
This paper presented the scientific flow implemented in MindLink Analyzer's \texttt{newBackend}: validated EEG acquisition, live digital filtering, spectral windowing, quality control, EMG-guarded feature extraction, baseline-referenced statistical inference, dependence-aware global testing, across-task ranking, and structured neuroprofile export. The system is designed for interpretable cognitive-state evidence from short single-channel EEG recordings while preserving statistical transparency and downstream inference boundaries.
