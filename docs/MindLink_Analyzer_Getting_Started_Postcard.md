# MindLink Analyzer Getting Started

### 1. Set Up The MindRove

1. Plug the MindRove Wi-Fi dongle into your computer.
2. Turn on the MindRove device.
3. Wear the headset so the sensors make firm, comfortable contact.
4. Keep the device close to the computer during the full session.

### 2. Connect To MindRove Wi-Fi

1. Open the Windows Wi-Fi menu.
2. Select `Wi-Fi 2` if it appears.
3. Choose the `MindRove BRT` Wi-Fi network.
4. Enter one of these passwords:

`#mindrove`

or

`@MDSPNeuroprofiler`

Leave the computer connected to the MindRove Wi-Fi network while using MindLink Analyzer.


### 3. Start MindLink Analyzer

1. Open MindLink Analyzer.
2. Select your region.
3. Sign in with your Mindspeller account.
4. Enter PARTNER ID (ask your coach or contact us).
5. On the Live EEG screen, wait for `Signal quality: Good`.

Do not start baseline calibration until the signal is good.

### 4. Complete Your Session

Follow the steps shown in the app:

1. Baseline calibration
2. Cognitive tasks
3. Analyze all tasks
4. Upload to Mindspeller

Keep sound on. The app uses beeps for countdowns and task completion.

### Quick Fixes

**No MindRove Wi-Fi:** check that the dongle is plugged in and the device is on.

**Cannot connect:** try both Wi-Fi passwords.

**Signal not good:** adjust the headset, keep hair away from sensors, and sit still.

**Session interrupted:** re-run the affected task before uploading.
